# Sample data for your own workspace

A small, fictional business (Vijay Textiles) in the kind of messy format real exports come in:
other column names, an Excel BOM, day-first dates, rupee symbols and commas.

In the app: create a workspace, open **Your data**, then upload in this order:
1. `buyers.csv`
2. `invoices_with_mistakes.csv` first, to see the row-by-row error report (nothing is imported)
3. `invoices.csv`
4. `payments.csv`
5. `nandini-boutique-contract.txt` as the contract for **Nandini Boutique**

Then ask: "Who owes me the most?", "What's the late fee for Nandini Boutique?",
or "Draft a gentle reminder for VT-103."
